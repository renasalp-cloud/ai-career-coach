# AI Career Coach Roadmap

This roadmap describes the long-term evolution of AI Career Coach.

---

# Milestone 1 — MVP CLI 

Status: Completed

## Goal

Build a working command-line application capable of analyzing a CV with a local LLM.

### Completed

- Project architecture
- Git repository
- GitHub repository
- README
- PDF Reader
- Text Cleaning
- CV Parser
- Structured Prompt
- Role Profiles (initial)
- Ollama integration
- Structured JSON output
- Pydantic validation
- CLI presentation

---

# Milestone 2 — Assessment Engine

Status: Completed

## Goal

Separate business logic from AI reasoning.

### Completed

- Candidate Profile domain model
- Generic Requirement Pipeline
- Assessment Engine
- Deterministic recommendation generation
- Deterministic learning roadmap generation
- Better prompt orchestration
- Consistent scoring
- Evidence-based reasoning

---

# Milestone 3 — Career Intelligence

Status: In Progress

## Goal

Improve analysis quality.

### Completed

- Skill normalization
- Duplicate skill detection
- Requirement category preservation
- Conservative deterministic matching
- Hallucination reduction

### Current Focus

- Robust Candidate Profile extraction
- Diverse CV layouts and document styles
- Improved semantic evidence
- Analysis quality improvements

---

# Milestone 4 — Job Matching

Status: In Progress

## Goal

Compare candidates against real job descriptions.

### Completed

- Job description requirement extraction
- CV vs Job comparison
- Match score
- Missing requirements

### Planned

- ATS compatibility
- Resume optimization

---

# Guiding Principle

Every milestone should improve one of these areas:

- Assessment quality
- Software architecture
- User experience

Features should never be added at the expense of code quality or maintainability.
